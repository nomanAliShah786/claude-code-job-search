# Changelog

## 2026-10-01: first public release

- Skills: `/fetch-jobs`, `/rank-jobs`, `/job-intake`, `/tailor-cv`, `/cover-letter`, `/ats-score`, `/outcome`, `/interview`.
- `/fetch-jobs` collects the last 30 days of ads from LinkedIn, Indeed, IrishJobs.ie, Jobs.ie and Glassdoor, with an adjustable delay between requests and phone notifications when a site needs you.
- A LaTeX CV template with an ATS-safe layout, plus `cv/build.sh`, which checks the page count, bullets, dashes and text extraction.
- A beginner guide, a Remote Control guide and a sample CV in the README.
